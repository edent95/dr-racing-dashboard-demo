01 · Master Flow

一张图看懂 Super Admin

每天从 Task Inbox 开始，先找异常，再进入实际案件，最后用 Analytics 与 Audit Log 检查结果。

Super Admin 登录全局管理范围
→
Task Inbox今天的任务入口
→
Staff Attention找出逾期与异常员工
贷款申请审核、补件、银行结果、结案
潜在客户Lead Pool、认领、跟进、转客户
日历监督回电、银行跟进、管理任务
经营分析批核率、来源、车型、员工表现
处理或分派让正确的人完成下一步
→
Analytics看结果与趋势
→
Audit Log谁在何时改了什么

核心概念：系统不是让员工自己猜状态，而是直接显示 Current Action、当前负责人和下一步动作。

02 · Ownership

三种角色，各自负责什么

客户最容易理解的方式：Sales 服务客户，Admin 处理银行，Super Admin 管全局和异常。

Super Admin

全局监督与最终控制

查看所有员工与案件、重新分配 Handler、管理账号/车型/银行、处理异常，并通过 Audit Log 追踪修改。

Admin

审核与银行流程

审核新申请、要求补件、提交银行、记录银行决定、Reject CODE 及下一次银行跟进。

Sales

客户与资料跟进

建立客户、收集文件、完成补件、联系获批客户、跟进潜在名单，并处理最终客户决定。

03 · Loan Application

贷款申请主流程

每个阶段都会产生明确的 Pending With 与 Current Action，任务自动进入对应员工的 Task Inbox。

1客户进入系统Sales 新增或客户链接提交
2NEW等待 Admin 审核
3文件检查完整则继续；缺件交回 Sales
4Submit to BankAdmin 提交并设置跟进
5Bank Decision记录银行正式结果

Need More Info

案件回到 Sales 补资料；Documents Ready 后交回 Admin 重新提交。

Rejected

Admin 必须填写 8 位 Reject CODE；Sales 决定结束案件或整理资料重新申请。

Approved

案件交回 Sales 联系客户；完成 Customer Contacted 后关闭当前工作。

Super Admin：监督与异常介入 Admin：审核与银行 Sales：客户与文件

潜在客户如何转成贷款申请

Lead Pool 管来源与可见范围，Follow Up 管实际联系，Customer Relationships 负责重复与风险检查。

CSV / 手动新增潜在客户进入 Lead Pool
→

05 · Client Talking Points

每个页面怎么向客户解释

不要介绍按钮细节，先告诉客户每个页面解决什么管理问题。

Task Inbox

系统自动整理今天需要处理的贷款、补件、银行和跟进任务。

“员工不需要自己找工作。”

Staff Attention

Super Admin 快速比较员工的逾期、待办和工作量，并可进入单人 Focus。

“老板一眼看到问题在哪里。”

Loan Applications

集中保存客户、文件、银行申请、Current Action 与完整贷款进度。

“一个客户只有一个工作真相。”

Lead Pool & Follow Up

管理名单来源、归属、联系记录、提醒和正式客户转化。

“名单不会散在个人手机里。”

Calendar

统一显示客户回电、银行跟进、潜在名单提醒及管理层指派任务。

“所有承诺都有日期。”

Customer Relationships

自动检查重复电话、IC、账户和 Email，协助识别重复或风险关系。

“相同资料会被系统主动发现。”

Analytics

查看申请量、批核率、来源、车型需求、员工表现和运营趋势。

“从感觉管理变成数据管理。”

Finance Center

Admin 管理成交接受、实体库存、交车、实收、利润及佣金付款状态。

“批准贷款和真正完成成交分开管理。”

Commission & Rewards

当前只开放收入结算：销售佣金读取 Finance Deal 的 Estimated、Earned、Payable、Paid 或 Reversed 状态；Mission 与 Team Battle 页面暂时隐藏，既有资料保留。

“每一笔佣金都有成交依据和付款状态。”

Audit Log

记录员工、时间、目标以及修改前后的内容。

“重要修改都有证据。”

System Settings

由 Super Admin 管理员工账号、车型价格、银行资料、Logo 与标准化规则。

“基础资料只维护一次，全系统共用。”

06 · 10-Minute Demo

建议的客户演示顺序

从日常工作开始，以经营监督结束；客户会更容易理解系统带来的实际价值。

0–1 min
登录与 Task Inbox说明系统如何自动产生每日任务。
1–2 min
Staff Attention选择一名员工，展示 Focus Mode。
2–5 min
Loan Application用 Current Action 解释审核、补件、银行与结案。
5–7 min
Lead Pool 与 Follow Up演示名单如何被认领、跟进并转为客户。
7–8 min
Calendar展示全员回电、跟进日期与管理任务。
8–9 min
Finance 与 Rewards展示成交、库存、佣金状态和员工结算。
9–10 min
Audit Log以完整追踪能力结束演示。
Closing
总结系统价值流程、责任、提醒、数据和审计在同一个系统。
“这不只是保存客户资料的系统。它会告诉每位员工下一步该做什么，让管理层看到案件卡在哪里，并保留完整修改记录。”
当前范围：Finance Center 与 Commission & Rewards 的收入结算已开放；Mission、Team Battle、Approval、Staff View 与内部 System Manual 仍暂不向客户开放。
