# Dr Racing Dashboard — Public Demo

Public, read-only style demo of the Dr Racing loan dashboard, in the same style as the
[ETReportHub public demo](https://edent95.github.io/daily-report-dashboard/demo/).

- **No login** — visitors enter directly as a demo Super Admin.
- **Fixed anonymized sample data** — every customer, lead, phone number and IC is fictional,
  generated by a deterministic seeder (`app/src/demo/demoData.ts`).
- **Browser-only** — Firebase is not configured in this build. All data lives in the
  visitor's own browser (localStorage) and **resets on every reload**.

## Layout

```
index.html   → redirects to demo/
demo/        → built static site (this is what GitHub Pages serves)
app/         → demo-mode source (main app + src/demo/* seeder, no Firebase secrets)
```

## Deploy (GitHub Pages)

1. Create a GitHub repo named `dr-racing-dashboard-demo` and push this folder to `main`.
2. Repo → Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The demo is then live at:
   `https://<your-username>.github.io/dr-racing-dashboard-demo/demo/`

## Rebuild the demo after changing the app or the sample data

```bash
cd app
nvm use          # Node 24
npm ci
npm run build:demo   # rebuilds into ../demo with VITE_DEMO_MODE=true
```

`VITE_DEMO_MODE=true` is what turns on the demo: `app/src/main.tsx` then runs
`app/src/demo/bootstrap.ts`, which seeds the sample dataset, signs the visitor in,
and shows the PUBLIC DEMO banner. A normal build (without the flag) contains none
of this behavior.
